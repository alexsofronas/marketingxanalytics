WORK WITH ALEX

A model can show you where to look. Only a test should decide where the money goes.

Alex Sofronas runs geo and incrementality tests for enterprise brands at PostPilot. He takes outside work too, and it fits best when finance has stopped trusting platform ROAS.

Saved on about $77M a year in media. Agency consolidation plus test and learn cut cost per sale 30%+.

B2B software

IBM

PostPilot
1,000+

Client QBRs from one reporting pipeline he built

What Alex does

  1. 01

    Incrementality and geo tests

    Alex measures what a channel added beyond the sales you'd have made anyway. Every test is sized before launch, so you don't spend months on one too small to read. Without a clean control group, he builds a synthetic one.

  2. 02

    Media mix models, checked by a test

    He'll model 15+ channels, but the biggest call still gets a live lift test before budget moves. That's how the 10x above was found.

  3. 03

    Attribution audits

    Before a number goes in front of the CFO, Alex goes back to the source data and re-derives it. Bad holdout or iROAS math gets fixed. At PostPilot he re-checked eight campaign claims.

  4. 04

    Reporting automation

    Pipelines in SQL and Python that take raw data all the way to a finished slide deck. One of them made the 1,000+ QBRs above.

  5. 05

    Picking an addressable media vendor

    He tests both vendors against one randomized holdout and writes the rules down before anyone sees a result. If neither beat the holdout, the report says so.
